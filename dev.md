# To-do List Dev Notes

I will divide the project into two development phases; Program Logic Phase and User Interface Phase.

## Phase One: Program Logic

This program needs to perform the following tasks:

1. Create/Edit/Remove To-do
2. Mark to-do as complete
3. Change to-do priority
4. Create/Edit/Remove to-do list group

### Create/Edit/Remove To-do

A To-do list is an object with several properties:

- `title`
- `description`
- `dueDate`
- `priority`

I know three methods to generate objects using a template:

1. Using object constructors
2. Using classes
3. Using factory functions
